# Customer Information App

1. Install Node.js LTS.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and put your Neon DATABASE_URL in it.
4. In the Neon SQL Editor, run `database/schema.sql`.
5. Run `npm start`.
6. Open http://localhost:3000

The database is the master record store. Excel is generated from Neon when Download Excel is clicked.
